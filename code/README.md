# 학습·평가에 사용한 코드

`runs/four_policies_full_20261028/src/run_experiment.py`는 네 가지 진행 방식을 각각 적용하고 모든 판단 상황을 수집한 최신 실험입니다. 같은 폴더의 `baseline_experiment.py`에는 자료 읽기, 후보 구성, 40개 변수, 규칙과 가상 미래 평가가 있습니다.

```text
code/
├── requirements.txt
├── src/download_data.py
└── runs/four_policies_full_20261028/src/
    ├── run_experiment.py
    └── baseline_experiment.py
```

## 재현 범위

분석에 사용한 소스의 보관본입니다. 스크립트는 `code/`를 원 프로젝트 루트로 보고 원본 사례, 과거 실험 모형과 기록의 해시를 확인합니다. 학습 모형과 체크포인트 전체를 이 폴더에 포함하지 않았으므로 바로 재학습하는 경량 패키지는 아닙니다.

1. `requirements.txt`의 환경 준비
2. [원본 데이터](https://doi.org/10.17632/3j52cjrm52.3)를 `data/raw/` 아래 수집
3. 스크립트에서 참조하는 원본 배치와 이전 실험 파일을 준비하고 새 실행 디렉터리에서 실행

검증 집합은 고정한 모형 점검에 사용했으며, 이번 재수집 과정에서 검증 성능을 보고 하이퍼파라미터를 새로 선정하지 않았습니다. 이미 검토한 평가자료의 재실험이므로 외부 자료의 새 검증과 구분합니다.

**실행 가능한 시연**은 저장소 루트의 웹사이트입니다. 웹 파일과 공개용 학습 결과는 기존 경로를 그대로 유지했습니다.
