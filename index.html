HOW IT WORKS

추천을 확인하고, 직접 판단하세요.

적재 위치를 바꾸면 이후 재취급도 달라질 수 있습니다.

01

배치와 출고 요청 확인

224개 공개 연구 배치 중 하나를 선택하거나 CSV를 불러옵니다. 현재 출고할 컨테이너는 노란색, 먼저 옮겨야 할 컨테이너는 주황색으로 표시합니다.

출고 요청 선택란에서 순서를 바꾸면 사용자 수정 시나리오로 전환됩니다.

02

후보 위치와 점수 비교

현재 적재 상태와 출고 확률로 40개 변수를 계산합니다. 학습한 ExtraTrees 모형으로 후보별 상대 비용을 예측하고 가장 낮은 후보를 추천합니다.

점수는 후보 사이의 우선순위를 비교하는 값입니다. 음수도 가능하며 실제 이동 횟수는 아닙니다.

03

승인하고 이력 확인

추천 위치 또는 다른 가능한 위치를 선택해 승인합니다. 변경된 배치에서 다음 추천을 다시 계산합니다. 자동 시연으로 전체 작업을 확인하거나 작업 이력을 CSV로 저장할 수 있습니다.

다른 위치를 선택하면 메모를 남길 수 있습니다.

어떤 데이터를 준비하나요?

‘현재 배치 CSV 내려받기’로 양식을 받을 수 있습니다. 각 행은 컨테이너 한 개입니다.

id
컨테이너 고유 이름
stack / tier
적재열 번호 / 바닥부터의 단 번호 (1부터 시작)
p0 ~ p11
구간 0~11의 출고 확률, 행별 합계 1. 구간은 출고 순번이 아닙니다.
order
시뮬레이션에서 시험할 출고 순번
stack_count
빈 열을 포함한 전체 적재열 수

실제 미래 출고 순서는 AI 입력에 사용하지 않습니다. order는 동일한 조건에서 작업 결과를 비교하기 위한 시뮬레이션 입력입니다.

적용 범위

동일 규격의 컨테이너로 구성한 한 개 배치를 다룹니다. 4~10개 적재열, 최대 3~6단, 6~40개 컨테이너 범위에서 입력할 수 있습니다.

현재 출고를 막는 최상단 컨테이너만 다른 열로 옮기며, 높이 제한을 지킵니다. 실제 장비 이동시간, 중량, 위험물, 냉동 컨테이너 조건과 다중 크레인은 포함하지 않습니다.

현장 검토 시에는 해당 터미널의 제약과 운영 기록을 추가해 검증해야 합니다. ‘승인’은 장비에 명령을 보내지 않습니다.

CSV는 브라우저 안에서 처리하며, 이 서비스에서 업로드하거나 저장하지 않습니다.

데이터와 모형

Zhanluo Zhang (2024), Probabilistic Container Relocation Problem, Version 3. CC BY 4.0. 확률 행을 정규화하고 독립 모형을 학습하여 브라우저 실행 형식으로 변환했습니다.

학습할 때는 같은 판단의 모든 후보를 동일한 가상 미래 12개로 평가했습니다. 실제 추천에서는 저장한 모형으로 후보 점수를 계산합니다. 컨테이너를 옮긴 뒤에는 바뀐 배치를 같은 모형에 입력합니다.

진행 방식별 학습자료 수집량
진행 방식경로이동 판단후보 자료

네 경로에서 발생한 모든 판단과 가능한 목적지를 수집했습니다. 가능한 모든 이동 경로를 완전 탐색한 것은 아닙니다. 서로 다른 경로에서 같은 상태가 다시 나타난 경우에도 자료를 유지했습니다.

출고 확률은 공개 자료의 값을 사용했습니다. 출고 확률을 새로 예측하는 모형을 학습한 것은 아닙니다. 출고 우선순위 규칙, 확률 위험 규칙과 미래 탐색에도 같은 확률을 제공했습니다.

이번 수치는 이전에도 사용한 공개 연구 자료에서 재평가한 결과입니다. 국내 터미널의 운영 기록이나 현장 실측 성과를 나타내지 않습니다.
